# Learning Rust

This repository documents my journey of learning the Rust programming language through "The Rust Programming Language" book. The repository is organized into three main sections: notes, code snippets, and projects.

## Project Structure

*   **`/notes`**: Contains my notes on various Rust concepts. These are typically Markdown files summarizing chapters or specific topics.
*   **`/code`**: This directory holds small, self-contained Rust code snippets that I write while learning. Each snippet is intended to demonstrate a specific feature or concept.
*   **`/projects`**: Larger, more complete projects are stored here. These are full-fledged Cargo projects that I build to apply and solidify my understanding of Rust.
